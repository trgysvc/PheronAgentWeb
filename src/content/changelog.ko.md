# 변경 기록

이 프로젝트의 모든 주요 변경 사항은 이 파일에 기록됩니다.

형식은 [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)를 기반으로 하며, 이 프로젝트는 [시맨틱 버전 관리](https://semver.org/spec/v2.0.0.html)를 따릅니다.

## [1.0.6] - 2026-08-01

### 추가됨
- **Lark Suite 통합** — 메시징, 채팅, 캘린더, Base, 문서, 작업을 위해 Lark/Feishu의 공식 MCP 서버를 브링유어오운앱 방식으로 연결합니다.
- **LemonSqueezy 통합** — 주문, 고객, 구독, 할인, 라이선스 키를 관리하기 위한 직접 REST 연동.
- **Kit(ConvertKit) 통합** — 구독자, 브로드캐스트, 시퀀스, 태그를 관리하기 위한 직접 REST 연동.
- **MCP Hub 연결 해제 지원** — 연결된 각 서비스마다 자격 증명을 지우고 연결을 해제하는 원클릭 방법이 추가되었습니다.
- **Audacity 통합** — 오디오 편집 및 이펙트를 위해 실행 중인 Audacity 인스턴스를 자체 스크립팅 프로토콜을 통해 직접 제어합니다.
- **Apple 메모, 미리 알림 및 Office 내보내기** — 네이티브 메모/미리 알림 지원, Numbers/Keynote/Pages에서의 실제 Excel/PowerPoint/Word 내보내기, 온디바이스 배경 제거.

### 수정됨
- **웹 검색 및 인용 신뢰성** — 누락된 검색 결과, 잘못된 "불완전한 답변" 거부, 잘못 표시된 인용을 포함한 일련의 리서치 답변 문제를 수정했습니다.
- **새 도구 검색 가능성** — 메모, 미리 알림, 배경 제거, Office 문서 도구가 이제 간단한 요청에서 정상적으로 접근 가능합니다.
- **다단계 작업 완료** — 에이전트가 다음 단계를 실행하지 않고 설명만 하거나, 보고서를 작성하지 않고 완료로 표시할 수 있었던 사례를 수정했습니다.
- **기억 및 회상 신뢰성** — "이것을 기억해" 요청이 이제 조용히 아무것도 하지 않는 대신 안정적으로 저장됩니다.
- **더 안전한 도구 재시도 로직** — 반복된 실패 후 비활성화된 도구가 이제 자동으로 복구되며, 영구적인 제한 사항은 재시도 대신 즉시 보고됩니다.
- **캘린더 날짜 정확성** — 이벤트가 잘못된 날짜로 조용히 저장될 수 있었던 버그를 수정했습니다.
- **Stripe 및 Git 통합 수정** — 상위 변경 후 Stripe의 액션 세트를 수정하고 Git MCP 통합을 안정화했습니다.
- **파일 및 폴더 작업 안전성** — 경로 권한 검사 및 폴더 이동/복사 동작의 예외 사례를 수정했습니다.
- **전반적인 안정성** — 텔레메트리 전송, 브라우저 자동화, 시간 제한 예산, 시스템 부하 감지에 대한 소소한 수정.

## [1.0.5] - 2026-07-24

### 수정됨
- **소스 인용 안전성** — 인용 안전 검사를 활성 실행 경로로 이동하여, 에이전트가 존재하지 않는 소스 URL, 날짜, 버전 번호를 인용할 수 있었던 문제를 수정했습니다.
- **복합 요청 실행** — 누락된 도구 호출을 강제하여, 복합적인 여러 부분으로 구성된 요청(예: 텔레메트리와 OS 버전을 함께 요청)이 답변의 절반만 반환될 수 있었던 문제를 수정했습니다.
- **셸 출력 리디렉션 안전성** — 단순한 단일 파일 셸 리디렉션(`command > file`)이 바이너리 보호 및 쓰기 안전 검사를 우회하는 것을 방지했습니다.
- **봇 감지 및 CAPTCHA 필터링** — 웹 검색이 이제 검색 엔진의 CAPTCHA/봇 확인 페이지를 감지하고 필터링하여 추론이 확인 텍스트의 영향을 받지 않도록 합니다.
- **Google 검색 JS 안정화** — 클라이언트 측 JavaScript 렌더링 완료를 기다려 Google 검색 결과 가져오기를 개선했습니다.
- **Safari 폴백 복원력** — 필요한 경우 명확한 권한 안내와 함께 검색 폴백을 위해 실제로 보이는 Safari 탭을 엽니다.
- **생체 인식 및 키체인 동시성** — Touch ID 시간 제한 처리를 수정하고, 백그라운드 키체인 읽기가 도구 사용 가능 여부 확인을 차단하지 않도록 했습니다.
- **데몬 재시도 제한** — 실패한 백그라운드 데몬 연결이 무기한 재시도되는 것을 방지했습니다.

### 추가됨
- **신뢰할 수 있는 소스 리서치** — 에이전트는 이제 타사 검색 스니펫보다 공식 프로젝트 데이터, 구조화된 사양, 직접 문서를 우선시합니다.
- **확장된 GitHub 도구 세트** — GitHub Actions, 코드 보안, Dependabot, 토론, 보안 권고, gist, 프로젝트, 라벨, 알림에 대한 접근이 추가되었습니다.

## [1.0.4] - 2026-07-06

### 추가됨
- **MCP 도구 브리지** — Pheron Agent가 이제 Git, Playwright 브라우저 자동화, Perplexity 웹 검색, Stripe, GitHub, Notion, Unreal Engine, Zapier를 포함한 외부 Model Context Protocol(MCP) 서버와 통합됩니다.
- **MCP Hub 및 연결** — 외부 도구 연결의 자격 증명을 쉽게 구성, 저장, 테스트할 수 있는 전용 카드 그리드 마법사를 설정 > 연결에 추가했습니다.
- **컨텍스트 인식 추천** — 작업에 자격 증명이 필요한 도구가 필요할 때, 에이전트가 이제 설정 > 연결에서 누락된 통합을 연결하도록 제안합니다.
- **통합 화면 및 접근성 추론** — 더 일관되고 안정적인 브라우저/화면 관련 작업을 위해 화면 캡처 설명, OCR, AX 트리 분석을 연결했습니다.
- **로컬 사용자 프로필** — 에이전트가 발견한 선호도와 사용자 신원 정보가 이제 읽기 쉬운 마크다운 프로필(`UserProfile.md`)에 저장됩니다.
- **성능 탭 재설계** — 설정 아래의 상태 및 분석 탭을 실시간 CPU, 메모리, 속도 사용 추세 차트가 있는 단일 탭으로 통합했습니다.
- **디스크 텔레메트리 지원** — 텔레메트리 보고서에 이제 CPU 및 메모리 통계와 함께 부팅 볼륨의 여유 공간이 포함됩니다.

### 수정됨
- **다중 턴 대화 컨텍스트** — 동일한 대화 스레드 내 연속된 턴 사이의 컨텍스트 손실을 수정하여, 에이전트가 직전 컨텍스트를 기억하도록 했습니다.
- **모델 컨텍스트 제한** — 더 많은 RAM을 가진 시스템에서 사용 가능한 토큰 창을 인위적으로 제한했던 로컬 모델 컨텍스트 예산 조정 문제를 수정했습니다.
- **메모리 루프 수정** — 사용자 회상 세부 정보를 조회할 때(예: "내 이름 기억해?") 발생하던 도구 호출 루프 트리거를 해결했습니다.
- **키체인 및 인증 안정성** — Notion/Zapier의 OAuth 흐름 콜백을 수정하고, 로컬 테스트 실행 중 삭제된 키체인 항목을 복원했습니다.
- **작업 전환 성능** — CPU 누수를 방지하기 위해 시간 초과 또는 작업 취소 시 백그라운드 프로세스와 명령 실행을 즉시 중지했습니다.
- **터키어 명령 전치사 라우팅** — "üzerinden"(경유하여)이 포함된 터키어 프롬프트가 수학/계산 경로로 잘못 전송되던 오라우팅 버그를 수정했습니다.

## [1.0.3] - 2026-06-19

### 추가됨
- **개인 기억 및 회상** — 에이전트가 이제 배경, 이력서, 선호도 등 명시적으로 공유한 사실을 물어볼 때 안정적으로 기억하고 표시합니다; 저장된 사실이 사실상 검색 불가능해질 수 있었던 심층 검색 격차를 해소했습니다
- **다국어 파일/폴더 명령** — "이 폴더 정리해줘" 형식의 요청이 이제 터키어/영어뿐 아니라 13개 언어로 인식됩니다(TR/EN에 더해 ES, FR, DE, PT, IT, RU, ZH, JA, KO, AR 추가)
- **MusicDNA 보고서 작업** — 분석 결과에 이제 생성된 `.dna.md` / `.report.plist` 파일로 바로 이동하는 "보고서 열기" 및 "Finder에서 보기" 버튼이 포함됩니다
- **텔레메트리 — Supabase 통합:** 모든 텔레메트리 이벤트가 이제 인증된 요청, 재시도 로직, 종료 시 동기 플러시와 함께 `telemetry_events`를 통해 흐릅니다
- **에너지 추적 — IOKit 기반:** `powermetrics`를 통한 실제 CPU+GPU+ANE 줄(Joule) 측정이 메뉴 막대의 노력 표시기에 실시간으로 표시됩니다
- **분석 기본 활성화:** 명시적인 설정이 없을 때 분석이 이제 기본적으로 활성화됩니다

### 수정됨
- **명확화 질문 후 컨텍스트 손실** — 에이전트의 후속 질문(예: "어떤 날짜 형식인가요?")에 답변하면 이전에는 대화가 관련 없는 결과로 벗어날 수 있었습니다("ram"이라는 우발적인 부분 문자열 일치가 이러한 답변을 잘못 라우팅했습니다); 에이전트는 이제 답변 후 원래 작업에 머무릅니다
- **더 빠른 개인 회상 응답** — 에이전트가 이전에 말한 내용을 조회할 때 낭비되는 추론 턴을 제거했습니다
- Apple Music 재생 및 볼륨 제어: 확인이 이제 실제 플레이어 상태를 반영하여, Music이 아직 실행 중이 아닐 때 발생하던 무음 실패를 수정했습니다
- 텔레메트리: RAM/추론 지표와 인증이 더 이상 오래되거나 0인 값을 보고하지 않으며, 실패한 분석 배치가 더 이상 조용히 실패하지 않습니다
- 디버그 빌드가 이제 올바른 개발 팀으로 서명되어 누락된 권한(entitlements)을 수정했습니다

## [1.0.2] - 2026-06-03

### 추가됨
- **백그라운드 작업 처리** — 작업이 여전히 실행 중인 동안 새 대화를 시작할 수 있습니다; 이전 대화는 사이드바에 ⟳ 표시와 함께 남아 백그라운드에서 계속됩니다

- **라이선스 딥링크** — 원클릭 활성화를 위한 `pheron://activate?key=...` URL 스킴
- Qwen3 Dense: 0.6B · 1.7B · 4B · 8B · 14B · 32B
- Qwen3 MoE: 30B-A3B · Coder-30B-A3B · Next-80B-A3B · 235B-A22B · Coder-480B-A35B
- Llama 4 Maverick(512GB)
- Mistral Small 3.2 24B · Devstral Small 24B · Mistral Large 123B · Devstral 2 123B
- DeepSeek V4 Flash(192GB)
- VLM: Qwen2.5-VL 7B(48GB 이상)

- 설정 → AI 탭에 이제 구성 섹션이 포함됩니다
- WebSearchTool 신뢰성 개선

### 수정됨
