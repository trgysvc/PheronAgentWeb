# 更新日志

本项目的所有重要变更都记录在此文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)，本项目遵循[语义化版本](https://semver.org/spec/v2.0.0.html)规范。

## [1.0.6] - 2026-08-01

### 新增
- **Lark Suite 集成** — 通过自带应用连接方式桥接 Lark/飞书官方 MCP 服务器，支持消息、聊天、日历、多维表格、文档和任务。
- **LemonSqueezy 集成** — 直接 REST 桥接，用于管理订单、客户、订阅、折扣和许可证密钥。
- **Kit（ConvertKit）集成** — 直接 REST 桥接，用于管理订阅者、群发邮件、序列和标签。
- **MCP Hub 断开连接支持** — 每个已连接的服务现在都可以一键清除凭据并断开连接。
- **Audacity 集成** — 通过其自身的脚本协议直接控制正在运行的 Audacity 实例，进行音频编辑和效果处理。
- **Apple 备忘录、提醒事项与 Office 导出** — 原生备忘录/提醒事项支持，从 Numbers/Keynote/Pages 导出真正的 Excel/PowerPoint/Word 文件，以及端侧背景移除。

### 修复
- **网页搜索与引用可靠性** — 修复了一系列研究回答问题，包括丢失的搜索结果、错误的"回答不完整"拒绝，以及被错误标记的引用。
- **新工具可发现性** — 备忘录、提醒事项、背景移除和 Office 文档工具现在可以通过简单请求正确访问。
- **多步骤任务完成** — 修复了 Agent 可能在未执行下一步的情况下描述该步骤，或在未撰写报告的情况下将其标记为完成的情况。
- **记忆与回忆可靠性** — "记住这个"类请求现在会可靠保存，而不是静默地不做任何操作。
- **更安全的工具重试逻辑** — 因反复失败而被禁用的工具现在会自动恢复，永久性限制会被立即报告而非重试。
- **日历日期准确性** — 修复了事件可能以错误日期静默保存的错误。
- **Stripe 与 Git 集成修复** — 在上游变更后修正了 Stripe 的操作集，并稳定了 Git MCP 集成。
- **文件与文件夹操作安全性** — 修复了路径权限检查以及文件夹移动/复制行为中的边缘情况。
- **总体可靠性** — 对遥测数据传输、浏览器自动化、超时预算和系统负载检测的小幅修复。

## [1.0.5] - 2026-07-24

### 修复
- **来源引用安全性** — 将引用安全检查移至活跃执行路径，修复了 Agent 可能引用不存在的来源 URL、日期或版本号的问题。
- **复合请求执行** — 通过强制执行缺失的工具调用，修复了复合多部分请求（例如同时询问遥测数据和操作系统版本）可能只返回一半答案的问题。
- **Shell 输出重定向安全性** — 阻止了简单的单文件 shell 重定向（`command > file`）绕过二进制保护和写入安全检查。
- **机器人检测与验证码过滤** — 网页搜索现在会检测并过滤掉搜索引擎中的验证码/机器人验证页面，防止推理受到验证文本的影响。
- **Google 搜索 JS 稳定性优化** — 通过等待客户端 JavaScript 渲染完成，改进了 Google 搜索结果的获取。
- **Safari 后备方案的稳健性** — 在需要时真正打开可见的 Safari 标签页作为搜索后备方案，并提供清晰的权限指引。
- **生物识别与钥匙串并发处理** — 修复了 Touch ID 超时处理，并解除了后台钥匙串读取阻塞工具可用性检查的问题。
- **守护进程重试限制** — 防止失败的后台守护进程连接无限期重试。

### 新增
- **权威来源研究** — Agent 现在优先使用官方项目数据、结构化规范和直接文档，而非第三方搜索摘要。
- **扩展的 GitHub 工具集** — 新增对 GitHub Actions、代码安全、Dependabot、讨论、安全公告、gist、项目、标签和通知的访问权限。

## [1.0.4] - 2026-07-06

### 新增
- **MCP 工具桥接** — Pheron Agent 现在可与外部 Model Context Protocol（MCP）服务器集成，包括 Git、Playwright 浏览器自动化、Perplexity 网页搜索、Stripe、GitHub、Notion、Unreal Engine 和 Zapier。
- **MCP Hub 与连接** — 在"设置 > 连接"中新增专用卡片网格向导，便于配置、保存和测试外部工具连接的凭据。
- **情境感知推荐** — 当任务需要受凭据保护的工具时，Agent 现在会在"设置 > 连接"中建议连接缺失的集成。
- **统一的屏幕与辅助功能推理** — 串联屏幕截图描述、OCR 和 AX 树分析，实现更连贯可靠的浏览器/屏幕相关操作。
- **本地用户档案** — Agent 发现的偏好设置和用户身份信息现在保存在可读的 Markdown 档案中（`UserProfile.md`）。
- **性能标签页重新设计** — 将"设置"下的"健康"和"分析"标签页合并为一个标签页，包含实时 CPU、内存和速度使用趋势图表。
- **磁盘遥测支持** — 遥测报告现在除 CPU 和内存统计外，还包括启动卷的可用空间。

### 修复
- **多轮对话上下文** — 修复了同一对话线程中连续轮次之间的上下文丢失问题，确保 Agent 记住即时上下文。
- **模型上下文限制** — 修正了本地模型上下文预算缩放问题，此前该问题在内存较大的系统上人为限制了可用的 token 窗口。
- **记忆循环修复** — 解决了在查询用户回忆细节时（例如"你还记得我的名字吗？"）触发工具调用循环的问题。
- **钥匙串与身份验证稳定性** — 修复了 Notion/Zapier 的 OAuth 流程回调，并恢复了本地测试执行期间被删除的钥匙串条目。
- **任务切换性能** — 在超时或任务取消时立即停止后台进程和命令执行，以防止 CPU 泄漏。
- **土耳其语命令介词路由** — 修复了包含"üzerinden"（通过）的土耳其语提示被错误发送到数学/计算路径的路由错误。

## [1.0.3] - 2026-06-19

### 新增
- **个人记忆与回忆** — Agent 现在能可靠地记住并在您询问时呈现您明确分享过的事实（背景、简历、偏好）；修复了一个深层检索缺陷，此前保存的事实可能实际上变得无法被搜索到
- **多语言文件/文件夹命令** — "整理这个文件夹"类请求现在支持 13 种语言识别（在土耳其语/英语基础上新增西班牙语、法语、德语、葡萄牙语、意大利语、俄语、中文、日语、韩语、阿拉伯语），不再仅限于土耳其语/英语
- **MusicDNA 报告操作** — 分析结果现在包含"打开报告"和"在 Finder 中显示"按钮，可直接跳转到生成的 `.dna.md` / `.report.plist` 文件
- **遥测 — Supabase 集成：** 所有遥测事件现在通过 `telemetry_events` 传输，具备身份验证请求、重试逻辑和退出时的同步刷新
- **能耗追踪 — 基于 IOKit：** 通过 `powermetrics` 进行真实的 CPU+GPU+ANE 焦耳测量，在菜单栏功耗指示器中实时显示
- **分析默认开启：** 在未明确设置偏好时，分析功能现在默认启用

### 修复
- **澄清问题后的上下文丢失** — 此前回答 Agent 的追问（例如"哪种日期格式？"）可能使对话偏离到无关结果（一个偶然的"ram"子字符串匹配错误路由了这些回复）；Agent 现在会在您回答后保持在原始任务上
- **更快的个人回忆响应** — 消除了 Agent 查找您之前告知内容时的一次无谓推理轮次
- Apple Music 播放和音量控制：确认信息现在能反映实际播放器状态，修复了 Music 尚未运行时的静默失败问题
- 遥测：RAM/推理指标和身份验证不再报告过期或零值；失败的分析批次不再静默失败
- 调试构建现在使用正确的开发团队签名，修复了缺失的权限（entitlements）
