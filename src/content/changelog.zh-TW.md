# 更新日誌

本專案的所有重要變更都記錄在此檔案中。

格式基於 [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)，本專案遵循[語意化版本](https://semver.org/spec/v2.0.0.html)規範。

## [1.0.6] - 2026-08-01

### 新增
- **Lark Suite 整合** — 透過自帶應用程式連接方式橋接 Lark/Feishu 官方 MCP 伺服器，支援訊息、聊天、行事曆、Base、文件和任務。
- **LemonSqueezy 整合** — 直接 REST 橋接，用於管理訂單、客戶、訂閱、折扣和授權金鑰。
- **Kit（ConvertKit）整合** — 直接 REST 橋接，用於管理訂閱者、群發郵件、序列和標籤。
- **MCP Hub 中斷連線支援** — 每個已連接的服務現在都可以一鍵清除憑證並中斷連線。
- **Audacity 整合** — 透過其自身的腳本協定直接控制執行中的 Audacity 執行個體，進行音訊編輯和效果處理。
- **Apple 備忘錄、提醒事項與 Office 匯出** — 原生備忘錄/提醒事項支援，從 Numbers/Keynote/Pages 匯出真正的 Excel/PowerPoint/Word 檔案，以及裝置端背景移除。

### 修正
- **網頁搜尋與引用可靠性** — 修正了一系列研究回答問題，包括遺失的搜尋結果、錯誤的「回答不完整」拒絕，以及被錯誤標記的引用。
- **新工具可發現性** — 備忘錄、提醒事項、背景移除和 Office 文件工具現在可以透過簡單請求正確存取。
- **多步驟任務完成** — 修正了 Agent 可能在未執行下一步的情況下描述該步驟，或在未撰寫報告的情況下將其標記為完成的情況。
- **記憶與回想可靠性** — 「記住這個」類請求現在會可靠儲存，而不是靜默地不做任何操作。
- **更安全的工具重試邏輯** — 因反覆失敗而被停用的工具現在會自動恢復，永久性限制會被立即回報而非重試。
- **行事曆日期準確性** — 修正了事件可能以錯誤日期靜默儲存的錯誤。
- **Stripe 與 Git 整合修正** — 在上游變更後修正了 Stripe 的操作集，並穩定了 Git MCP 整合。
- **檔案與資料夾操作安全性** — 修正了路徑權限檢查以及資料夾移動/複製行為中的邊緣情況。
- **整體可靠性** — 對遙測資料傳輸、瀏覽器自動化、逾時預算和系統負載偵測的小幅修正。

## [1.0.5] - 2026-07-24

### 修正
- **來源引用安全性** — 將引用安全檢查移至活躍執行路徑，修正了 Agent 可能引用不存在的來源 URL、日期或版本號的問題。
- **複合請求執行** — 透過強制執行缺少的工具呼叫，修正了複合多部分請求（例如同時詢問遙測資料和作業系統版本）可能只回傳一半答案的問題。
- **Shell 輸出重新導向安全性** — 阻止了簡單的單一檔案 shell 重新導向（`command > file`）繞過二進位保護和寫入安全檢查。
- **機器人偵測與驗證碼過濾** — 網頁搜尋現在會偵測並過濾掉搜尋引擎中的驗證碼/機器人驗證頁面，防止推理受到驗證文字的影響。
- **Google 搜尋 JS 穩定性優化** — 透過等待用戶端 JavaScript 渲染完成，改進了 Google 搜尋結果的擷取。
- **Safari 備援方案的穩健性** — 在需要時真正開啟可見的 Safari 分頁作為搜尋備援方案，並提供清楚的權限指引。
- **生物辨識與鑰匙圈並行處理** — 修正了 Touch ID 逾時處理，並解除了背景鑰匙圈讀取阻擋工具可用性檢查的問題。
- **守護程序重試限制** — 防止失敗的背景守護程序連線無限期重試。

### 新增
- **權威來源研究** — Agent 現在優先使用官方專案資料、結構化規格和直接文件，而非第三方搜尋摘要。
- **擴充的 GitHub 工具集** — 新增對 GitHub Actions、程式碼安全、Dependabot、討論、安全公告、gist、專案、標籤和通知的存取權限。

## [1.0.4] - 2026-07-06

### 新增
- **MCP 工具橋接** — Pheron Agent 現在可與外部 Model Context Protocol（MCP）伺服器整合，包括 Git、Playwright 瀏覽器自動化、Perplexity 網頁搜尋、Stripe、GitHub、Notion、Unreal Engine 和 Zapier。
- **MCP Hub 與連線** — 在「設定 > 連線」中新增專用卡片網格精靈，便於設定、儲存和測試外部工具連線的憑證。
- **情境感知建議** — 當任務需要受憑證保護的工具時，Agent 現在會在「設定 > 連線」中建議連接缺少的整合。
- **統一的畫面與輔助使用推理** — 串聯畫面擷取描述、OCR 和 AX 樹狀結構分析，實現更連貫可靠的瀏覽器/畫面相關操作。
- **本機使用者檔案** — Agent 發現的偏好設定和使用者身分資訊現在儲存在可讀的 Markdown 檔案中（`UserProfile.md`）。
- **效能標籤頁重新設計** — 將「設定」下的「健康」和「分析」標籤頁合併為一個標籤頁，包含即時 CPU、記憶體和速度使用趨勢圖表。
- **磁碟遙測支援** — 遙測報告現在除 CPU 和記憶體統計外，還包括開機磁碟區的可用空間。

### 修正
- **多輪對話上下文** — 修正了同一對話串中連續輪次之間的上下文遺失問題，確保 Agent 記住即時上下文。
- **模型上下文限制** — 修正了本機模型上下文預算縮放問題，此前該問題在記憶體較大的系統上人為限制了可用的權杖視窗。
- **記憶迴圈修正** — 解決了在查詢使用者回想細節時（例如「你還記得我的名字嗎？」）觸發工具呼叫迴圈的問題。
- **鑰匙圈與身分驗證穩定性** — 修正了 Notion/Zapier 的 OAuth 流程回呼，並復原了本機測試執行期間被刪除的鑰匙圈項目。
- **任務切換效能** — 在逾時或任務取消時立即停止背景處理程序和命令執行，以防止 CPU 洩漏。
- **土耳其語命令介係詞路由** — 修正了包含「üzerinden」（透過）的土耳其語提示被錯誤傳送到數學/計算路徑的路由錯誤。

## [1.0.3] - 2026-06-19

### 新增
- **個人記憶與回想** — Agent 現在能可靠地記住並在您詢問時呈現您明確分享過的事實（背景、履歷、偏好）；修正了一個深層檢索缺陷，此前儲存的事實可能實際上變得無法被搜尋到
- **多語言檔案/資料夾指令** — 「整理這個資料夾」類請求現在支援 13 種語言辨識（在土耳其語/英語基礎上新增西班牙語、法語、德語、葡萄牙語、義大利語、俄語、中文、日語、韓語、阿拉伯語），不再僅限於土耳其語/英語
- **MusicDNA 報告操作** — 分析結果現在包含「開啟報告」和「在 Finder 中顯示」按鈕，可直接跳轉到產生的 `.dna.md` / `.report.plist` 檔案
- **遙測 — Supabase 整合：** 所有遙測事件現在透過 `telemetry_events` 傳輸，具備身分驗證請求、重試邏輯和結束時的同步清除
- **能耗追蹤 — 基於 IOKit：** 透過 `powermetrics` 進行真實的 CPU+GPU+ANE 焦耳測量，在選單列功耗指示器中即時顯示
- **分析預設開啟：** 在未明確設定偏好時，分析功能現在預設啟用

### 修正
- **釐清問題後的上下文遺失** — 此前回答 Agent 的追問（例如「哪種日期格式？」）可能使對話偏離到無關結果（一個偶然的「ram」子字串比對錯誤路由了這些回覆）；Agent 現在會在您回答後保持在原始任務上
- **更快的個人回想回應** — 消除了 Agent 查找您先前告知內容時的一次無謂推理輪次
- Apple Music 播放和音量控制：確認資訊現在能反映實際播放器狀態，修正了 Music 尚未執行時的靜默失敗問題
- 遙測：RAM/推理指標和身分驗證不再回報過期或零值；失敗的分析批次不再靜默失敗
- 偵錯組建現在使用正確的開發團隊簽署，修正了缺少的權限（entitlements）
